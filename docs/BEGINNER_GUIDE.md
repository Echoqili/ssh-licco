## 1. 这是什么工具？

一句话：**它是你的「远程操作管家」。**

你把服务器地址和密码告诉它，然后像聊天一样对它说话，它就去服务器上帮你执行命令、看 Docker、传文件、查日志，再把结果讲给你听。

你不用记任何 Linux 命令，也不用登进服务器敲字 —— 只要**用大白话描述你想干嘛**就行。

---

## 2. 需要准备什么

| 你需要有 | 说明 |
|---------|------|
| 一台 Windows / macOS / Linux 电脑 | 后面步骤在 Windows 上演示，其他系统大同小异 |
| Python 3.10 或更新版本 | 见 [第一步](#3-第一步安装) 检测方法 |
| 一个能连的服务器 | IP、账号、密码（例如 `192.168.58.130`、`licco`、`licco123`） |
| Trae / Cursor / Claude Desktop 等支持 MCP 的编辑器 | 装好即可，后面的截图示例用 Trae |

> 💡 你的服务器可能是一台虚拟机、云主机或局域网机器，只要它开启了 SSH 服务（一般是 22 端口）就可以。

## 3. 第一步：安装

打开「命令行 / 终端 / PowerShell」窗口，输入下面命令，回车：

```bash
npm install -g ssh-licco
```

> ⌨️ 第一次使用时不要手动改任何配置，直接跑，它会自动帮你：
> 找到 Python → 建立独立环境（`~/.ssh-licco-venv`）→ 装好所有依赖 → 准备就绪。

**检测一下是否装好**，输入：

```bash
ssh-licco
```

如果**没有报错**、命令能正常启动（有时会等它自己初始化），就说明安装成功了。

> 📌 常见坑：如果报错 `did not find executable at D:\software\anaconda\python.exe`，
> 说明这个独立环境和真实的 Python 对不上了，**最简单的方法是删掉重建**（见 [第 8 节](#8-卡住了看这里) 第 2 条）。

---

## 4. 第二步：告诉工具你的服务器（只需一次）

这是一个「备忘录」，把你服务器的信息写进去，以后就不用每次都念密码了。

找到文件：**项目目录下的 `config/hosts.json`**。

用记事本打开，把里面填成你自己的服务器（**照葫芦画瓢，一个 `{...}` 就是一台服务器**）：

```json
{
  "ssh_hosts": [
    {
      "name": "我的服务器",
      "host": "192.168.58.130",
      "port": 22,
      "username": "licco",
      "password": "licco123"
    }
  ]
}
```

各字段含义：

| 字段 | 填什么 |
|------|--------|
| `name` | 给这台服务器起的**名字**（随便取，方便你记住，后面提问时叫它） |
| `host` | 服务器 **IP 或域名** |
| `port` | 端口，一般就是 `22` |
| `username` | 登录**用户名** |
| `password` | 登录**密码** |

保存文件即可，不用干别的。

## 5. 第三步：在编辑器里启用

这是**开机步骤**，以后每次用之前做一次就行。

1. 🖱️ 打开 Trae，点左下角设置，搜索 **MCP**
2. 🖱️ 点「**添加新的 MCP 服务器**」
3. ⌨️ 名称随便填，例如 `ssh`
4. ⌨️ 命令一栏粘贴：

   ```
   C:\Users\你的用户名\.ssh-licco-venv\Scripts\ssh-licco.exe
   ```

   > 把「你的用户名」换成你电脑的用户名。如果你在 macOS / Linux，则填：
   > `/home/你的用户名/.ssh-licco-venv/bin/ssh-licco`

5. 🖱️ 保存，回到对话窗口

如果一切正常，对话窗口里会出现一大串可用的功能（比如「连接服务器」「执行命令」「Docker 管理」等），就说明它已经接通了。

## 6. 开始提问

用大白话说话就行。工具理解「帮我」「查看」「上传」这类词，并自动决定用哪个工具。

**最小示例** —— 连接并查看服务器上的 Docker 镜像：

> 🖱️ 在对话框里输入：
>
> ```
> 连接我的服务器，然后看看上面有哪些 Docker 镜像
> ```

它就会自动：连上 `我的服务器` → 帮你跑 `docker images` → 把镜像列表整理给你看。

> 如果文档里有不止一台服务器而你不想说名字，就说清楚要连哪台，例如：
> 「连接**我的服务器**（192.168.58.130）」。

第一次连接时如果提示「是否保存主机密钥」，选**确定 / 接受**即可。

## 7. 常用例子

照着这些说法提问，改掉括号里的内容就能用：

**① 执行任意命令（想知道什么都行）**
> 在服务器上运行 `free -h`，告诉我内存使用情况

**② 看 Docker 容器**
> 列出服务器上所有正在运行的容器

**③ 传文件**
> 把本地这个 `index.html` 上传到服务器的 `/var/www/html` 目录

**④ 看某服务状态**
> 检查一下 MySQL 是否正常运行，起没起来

**⑤ 看日志**
> 查看容器 `nginx` 最近 50 行日志

**⑥ 用完断开**
> 断开所有 SSH 连接

## 8. 卡住了？看这里

| 现象 | 原因 | 怎么做 |
|------|------|--------|
| 输入 `ssh-licco` 提示命令不存在 | 没装好 / PATH 问题 | 重新执行第 3 步的安装命令 |
| 报错 `did not find executable at ...\python.exe` | 独立环境里的 Python 指向了不存在的路径（比如 Anaconda 搬家了） | **重建环境**：删除 `C:\Users\你的用户名\.ssh-licco-venv` 整个文件夹，再重新跑第 3 步的安装命令 |
| 装依赖时报 `Could not find a version that satisfies ... setuptools` | 国内镜像源没有这个包 | 换官方源安装：`C:\Users\你的用户名\.ssh-licco-venv\Scripts\python.exe -m pip install -e 项目路径 -i https://pypi.org/simple`（官方源会慢一些，耐心等） |
| 编辑器里看不到任何工具 | MCP 没配置好 / 配置改了没重启 | 检查第 5 步命令是否正确，重启 Trae |
| 连不上服务器 | IP/账号/密码写错 或 服务器没开 SSH | 检查第 4 步 hosts.json 里的内容，用 SSH 客户端手动登录确认能连再回来 |
| 命令被拦截了 | 安全策略拦住了危险命令 | 不是写错，是为了保护你。换一种安全的说法重新提问 |
